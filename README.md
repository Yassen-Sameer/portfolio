# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built to showcase my web development projects, skills, and experience as a Front-End Developer.

## 🚀 Live Demo

[View Live Project](https://yassensamer258-commits.github.io/portfolio-master/) *(Replace with your actual hosted link)*

---

## 🛠️ Features

* **Responsive Design:** Optimized for all screen sizes, from mobile phones to desktop displays.
* **Modern UI/UX:** Styled with clean typography, smooth transitions, and a personalized dark aesthetic.
* **Project Showcase:** Interactive grid displaying featured projects with images and details.
* **Asset Optimization:** Efficient asset structure using fast-loading `.webp` images and optimized CSS.

---

## 🧰 Tech Stack & Libraries

* **HTML5:** Semantic markup for structure and accessibility.
* **CSS3:** Custom styles (`yassen.css`, `style.css`) with CSS Grid & Flexbox.
* **Bootstrap:** Responsive utility classes and grid system (`bootstrap.min.css`).
